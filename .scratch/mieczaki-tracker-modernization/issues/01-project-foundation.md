# 01 — Project Foundation & Vite/TypeScript Setup

**What to build:**
Set up the project foundation using Vite, TypeScript, Vitest, and Biome. Configure package scripts for building, testing, linting, and development server.

**Blocked by:** None — can start immediately.

**Status:** completed

## Acceptance criteria

- [x] `package.json` initialized with Vite, TypeScript, Vitest, Biome, and Chart.js dependencies.
- [x] TypeScript configuration (`tsconfig.json`) configured for strict mode.
- [x] Biome configuration (`biome.json`) configured for formatting and linting.
- [x] Vitest configuration (`vite.config.ts`) set up with JSDOM environment.
- [x] Basic directory structure created (`src/`, `src/components/`, `src/services/`, `data/`, `public/avatars/`, `tests/`).
- [x] `npm run build`, `npm run test`, and `npm run check` commands pass.
