## Environment gotchas (important — non-obvious)

- **Chrome needs NSS/ALSA libs not installed system-wide** (`libnspr4`, `libnss3`,
  `libasound2`). The scraper auto-provisions them: `_ensure_browser_libs()`
  runs `apt-get download` + `dpkg-deb -x` and extracts the `.so`s into
  `~/.local/share/mieczaki-tracker/chrome-libs/`, then sets `LD_LIBRARY_PATH`.
  It also `pkill -f agent-browser-linux` before scraping so the auto-launched
  server inherits the env (a stale server won't pick up the new path).
- **`sudo` requires a TTY** on this box — can't run non-interactive sudo. That's
  why the libs are provisioned locally instead of `apt-get install`.
- **`_ab()` in the scraper captures stdout via a temp file, not a pipe** — a
  lingering Chrome subprocess otherwise holds the pipe and the scraper hangs at
  exit. Cleanup closes the browser and `pkill`s the server afterward.
- `agent-browser` prerequisite: `npm i -g agent-browser && agent-browser install`.
